# Kotlin judge templates

- [Built-in Scanner](scanner-io/README.md): current preferred template for
  practice; `nextInt`, `nextLong`, `nextDouble`, `next`, and `nextLine` examples.
  Includes an AcWing 104 input starter without the algorithm.
- [Buffered input](console-io/README.md): custom token reader and buffered
  output for when Scanner performance becomes a concern.

Copy the chosen Main.kt, adapt the input and solution, then submit it as a
Kotlin/JVM console program to a judge that supports it.
